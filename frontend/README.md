# AI Summarizer — Frontend

This is the React Single Page Application (SPA) frontend for **AI Summarizer**.

Please refer to the main [Root README.md](../README.md) for full project documentation, architecture details, backend setup, and usage instructions.

## Quick Start (Frontend Only)

```bash
# Install dependencies
npm install

# Start React Dev Server
npm start
```
Runs the app on `http://localhost:3000`.
Make sure the Flask backend server is running on `http://127.0.0.1:5000`.
